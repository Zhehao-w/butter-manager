# 图标与侧栏立绘

应用固定使用新版图标和第二套侧栏立绘，与 EXE 和原生窗口图标一致。设置页不再提供外观切换；旧的外观读取、写入及启动迁移流程已移除。现有用户目录中的 `appearance.json` 保持原位，但不再读取或改写。

侧栏立绘固定贴底，并随窗口裁切显示；顶部装饰与详情 Hero 使用现有静态图片。图像来源、提示词和尺寸转换记录见 [图像说明](../src/assets/README.md) 与 [原生图标说明](../src-tauri/icons/README.md)。本轮清理不修改当前图片或布局。

Windows 资源管理器可能缓存 EXE 的旧文件图标。项目不实现自修改 EXE、外观切换助手或后台替换服务。
