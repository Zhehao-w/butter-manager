## 保留的性能发现

1. **历史更新很多时，管理器启动可能变慢。** 在主窗口创建前打开导入记录时，含更新信息的历史项目也会加载文件清单，单个清单的允许上限为 256 MiB。这里确认了读取路径，尚未测量真实库的启动占比。后续可单独评估对已完成更新按需加载清单，覆盖旧日志、缺失清单和重启回滚。[导入历史加载](../src-tauri/src/importer.rs)
2. **大量 JSON 存档可能拖慢切槽。** 编辑器按槽位 ID 重新定位时会再枚举关联目录，格式识别可能读取其他候选 JSON。若优化，仍须在读写前核对目录归属、文件身份和修订号。尚未测量真实游戏的切槽耗时。[槽位发现与解析](../src-tauri/src/save_editor/mod.rs)
