# 配置同步与最近运行排序（1.5.4）

完整手动扫描补齐已有记录的未识别引擎，包括旧 Import 标为手动的 Unknown；已知的手动引擎保持。补空存档仍使用保存配置，不增加启动时扫描，也不覆盖已配置的路径。

扫描同步只合并请求以来未被用户改动的字段。名称、别名或存档路径的较新编辑保持；启动目标、模式、参数和 loader 作为整体保留，避免拼接出混合配置。打开中的详情接收未编辑字段的自动补全，同时保留其他未保存草稿。

Import 更新在新包引擎未知时默认继承已有引擎；新包明确识别的引擎继续采用。用户在引擎控件中明确选择 Unknown 时，本次更新按该选择保存；以后完整扫描识别成功仍可补齐。仅新生成计划解析默认值，已有 Journal 的引擎值不重解释；新增可选选择标记不改变 schema 15，更新和回退保存实际采用的配置。

最近运行排序在启动成功后更新，保持滚动位置，列表与虚拟卡片使用约 180ms 的短距离位移动画。动画保留虚拟行的定位 transform；切换视图 / 排序时放弃旧动画。系统减少动态效果时立即重排，启动失败不改变运行时间或顺序，不自动滚动到顶部。

## 手动验收

1. 手动扫描期间打开详情，等待自动补齐 Bakin / MTool，确认未编辑字段同步；修改名称后保存，自动补齐的配置保持。
2. 扫描同步返回前保存名称或启动配置，确认旧响应不使新资料退回。
3. Unknown 旧记录后续识别为 Unity 等引擎时补齐；已知的手动引擎保持。新版未识别的更新保留旧引擎，明确选择 Unknown 也可提交，版本回退恢复原引擎。
4. 最近运行排序下分别在列表和超过 50 项的虚拟卡片中启动靠后游戏；请求期间保持原位，成功后平滑重排，当前位置不跳顶。检查快速重复请求、失败、减少动态效果和高 DPI。

本机验收使用用户已有应用；自动回归仅使用合成目录、临时数据库和 DOM / 进程模拟，不复制或备份正式资料。
