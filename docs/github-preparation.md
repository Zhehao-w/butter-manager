# GitHub 首次发布准备

日期：2026-10-08。目标仓库为 [Zhehao-w/butter-manager](https://github.com/Zhehao-w/butter-manager)。本轮只准备本地源码和仓库配置，不创建远端提交、PR、标签或 Release。

## 提交范围

提交应用源码、测试夹具代码、数据库迁移、两个依赖锁文件、构建配置、开发脚本、功能说明、MIT 许可、资源来源和必要的第三方许可。应用图标及插画由提供者确认是 GPT 生成且允许公开分发。

不提交实际数据库及 WAL/SHM、用户配置、导入恢复记录、游戏/存档、依赖缓存、本地工具链、日志、exe 或其他构建产物。项目根目录的凭据与环境配置由忽略规则保护；示例配置可通过 .env.example 提交。

## 自动检查

Windows 检查覆盖：锁定依赖安装、代码格式、前端测试和构建、隔离的后端测试、全部目标 Clippy、Windows exe 构建。Actions 使用核对过的上游提交 SHA；读取源码权限，关闭检出凭据持久化，没有发布或上传步骤。

工具版本与本轮开发环境对齐：Node.js 24.19.0、pnpm 11.25.0、Rust 1.99.0。GitHub Actions 需在首次推送后运行一次才能确认云端环境通过，不能把本地检查当成云端运行结果。
