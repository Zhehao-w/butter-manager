# 外置 MTool 翻译包推荐（1.5.1）

Import 可为有明确翻译说明及配套字典、没有随包工具或启动 BAT 的游戏推荐公共 MTool。本功能随 1.5.1 交付，沿用 schema 15；从 1.5.0 升级无需数据库迁移。

## 识别条件

必须同时满足以下条件：

- 扫描完整完成，目标为当前游戏目录内的 EXE。不再限定 MV / MZ；其他引擎和未识别引擎也可推荐。引擎证据冲突、WOLF 和 QSP 不推荐，文档及外部播放器不套用此规则。
- EXE 同目录存在候选 `.txt` 说明，文件名含 MTool、「翻译 / 翻譯」、`translation / translate`、`readme` 或「说明」。内容需明确说明用 MTool 打开游戏、加载翻译等操作；只有 MTool 字样或官网链接不够，明确表示无需、禁止或不建议使用 MTool，或 MTool 无法打开游戏 / 加载翻译时不推荐。否定判断围绕工具及其动作，不将「不附带 MTool」或「不要直接打开游戏，请用 MTool」当作禁用说明。
- 同目录存在翻译字典候选：优先文件名含「翻译 / 翻譯」、`translation / translate` 的 JSON；其他名称必须被有效说明明确提及。不遍历读取普通 JSON，不将 `settings.json.bak` 或目录外路径当作同名引用。
- 候选内容符合扁平的「原文 → 译文」字符串字典结构。抽样最多 32 个完整条目，至少 4 个，检查到的条目均须为字符串到字符串；允许原文与译文相同，不要求特定语言。数字、布尔值、嵌套对象和数组不能作为这种字典的正面证据。

官方 `https://mtool.app` 链接是可选的辅助证据，缺少链接仍可满足以上条件；存在宣称该地址的链接时拒绝相似域名、用户信息伪装及其他链接参数中嵌入的网址。不访问任何链接或执行说明中的指令。

识别最多枚举该目录 256 项，优先 MTool / 翻译文件名并按名称排序检查最多 4 份说明，每份不超过 64 KiB，支持 UTF-8 / UTF-16。最多检查 4 个符合名称或引用条件的字典，每个只读取前 64 KiB，使用 JSON 解析器抽样字符串映射，不完整加载字典。字典支持 UTF-8 和 UTF-8 BOM。大文件允许前缀在字符串或条目中途截断；这只是格式抽样，不保证整个字典有效或可由 MTool 加载。复用扫描预算、取消及路径 / 链接保护，路径保留原始大小写。

## Import 与启动

首次导入分析默认勾选「公共 MTool」，卡片使用现有浅蓝胶囊样式显示「外置翻译包」，悬停说明推荐原因，避免与「公共 MTool 启动」重复。可以取消，手动修改和已有选择不会被后续分析重新勾回；更新已有游戏时仍沿用原有启动配置继承 / 显式覆盖规则。

未配置公共工具时沿用既有配置提示；实际启动复用已有链路：Bakin 使用专用 BakinLauncher，其他普通注入按当前 EXE 的真实位数自动选择公共目录中的 loader，不把 x64 游戏固定为 32 位。已手动设置的 loader 继续按原规则处理。推荐说明包需要公共 MTool，不保证所有未知引擎都兼容；此变更不增加新的注入能力、不更改公共 injector、不改写已有游戏启动方式、不自动挂载字典，也不扩展 WOLF 支持。

仅有翻译材料时，不把说明或 JSON 识别为随包工具，不显示工具清理勾选；它们作为普通游戏材料保留。另有实际随包工具时，按 [随包 MTool 清理](import-mtool-cleanup.md) 单独选择整目录回收，所选一级目录内的全部文件随目录一起回收；保留路径身份、失败反馈与文件任务保护。不执行下载包脚本。

## 手动验收

1. 在独立测试目录准备游戏 EXE、明确翻译说明及至少 4 项字符串映射的合成字典，字典分别使用中文翻译名、英文 translation 名及说明明确引用的其他名称。省略官网链接也应推荐；确认默认勾选、推荐原因和策略，没有随包工具清理项。
2. 导入后在游戏详情的「启动配置 → 高级启动选项」查看「预览调试 BAT」（仅预览文本），确认普通注入的 x64 EXE 自动选择 `loaders/mzHook.dll`、x86 使用 `loaders/mzHook32.dll`，Bakin 保留专用策略。导入后按选定策略启动，字典仍由用户按 MTool 自身流程挂载。
3. 取消公共 MTool，再切换设置或重新分析，确认选择保留；生成计划及导入后的配置正确。翻译说明与 JSON 未被回收或改写。
4. 缺字典、未引用的普通名称 JSON、配置 / 数组结构、弱说明、伪造官方域名、链接文件、引擎冲突、QSP 或 WOLF 样本不应自动推荐。
5. 游戏详情切换「记录与管理」及其他 Tab，确认首张内容卡片顶部对齐，「目录与库记录」标题使用相同的图标底座、字号和间距，并检查窄窗口 / 高 DPI。

自动化只使用隔离临时数据库、目录和合成文件，不提交用户提供的翻译字典。Windows EXE 由现有 GitHub Actions 构建；自动化通过不代替真实游戏启动和界面验收。
