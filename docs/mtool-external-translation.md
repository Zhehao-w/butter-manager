# 外置 MTool 翻译包推荐（未发布）

Import 可为已有普通 MTool 注入支持的 RPG Maker MV / MZ 推荐公共 MTool，适用于包内只有翻译说明和字典、没有随包工具或启动 BAT 的情况。应用版本仍为 1.5.0，沿用 schema 15；正式版 1.5.0 尚不包含此补充。

## 识别条件

必须同时满足以下条件：

- 扫描完整完成，选中的游戏 EXE 具有明确的 MV / MZ 引擎证据；WOLF、未知或引擎冲突不推荐。
- EXE 同目录的 `.txt` 说明文件名同时包含 MTool 和「翻译」或 `translation`；内容明确指向已有 / 自备 MTool 或包内不附带工具，并说明用其打开游戏及翻译文件。
- 说明中含独立的 `https://mtool.app` 官方链接，可带路径或查询参数；相似域名、用户信息伪装及其他链接参数中嵌入的网址不算官方链接。不访问链接或执行说明中的指令。
- 同目录有非空的 `翻译文件.json`，或说明明确提及的 `translation.json`。普通配置 JSON、只有 MTool 字样、只有官网链接或缺少字典均不推荐。

识别最多枚举该目录 256 项，按文件名排序检查最多 4 份候选说明；每份不超过 64 KiB，支持 UTF-8 / UTF-16。复用扫描预算、取消及路径 / 链接保护；不能确认时保留原启动选择。字典只检查文件身份、名称与大小，不读取或解析其内容。路径保留原始大小写。

## Import 与启动

首次导入分析默认勾选「公共 MTool」，卡片显示「外置翻译包 · 推荐公共 MTool」。可以取消，手动修改和已有选择不会被后续分析重新勾回；更新已有游戏时仍沿用原有启动配置继承 / 显式覆盖规则。

未配置公共工具时沿用既有配置提示；实际启动复用普通注入链路，根据当前 EXE 的真实位数自动选择公共目录中的 loader，不把 x64 游戏固定为 32 位。已手动设置的 loader 继续按原规则处理。此推荐不更改公共 injector、不改写已有游戏启动方式、不自动挂载字典，也不扩展 WOLF 支持。

翻译说明与 JSON 不进入随包 MTool 清理目标，不出现随包工具清理勾选；导入后作为普通游戏材料保留。原随包工具白名单、路径身份、失败反馈与文件任务保护保持。不执行下载包脚本。

## 手动验收

1. 在独立测试目录准备 MV / MZ EXE、明确翻译说明和配套字典；配置公共 MTool，添加到 Import。确认默认勾选、推荐原因和普通注入策略，没有随包工具清理项。
2. 导入后在游戏详情的「启动配置 → 高级启动选项」查看「预览调试 BAT」（仅预览文本），确认 x64 EXE 自动选择 `loaders/mzHook.dll`；x86 使用 `loaders/mzHook32.dll`。导入后按选定策略启动，字典仍由用户按 MTool 自身流程挂载。
3. 取消公共 MTool，再切换设置或重新分析，确认选择保留；生成计划及导入后的配置正确。翻译说明与 JSON 未被回收或改写。
4. 缺字典、普通 JSON、弱说明、伪造官方域名、链接文件或 WOLF 样本不应自动推荐。
5. 游戏详情切换「记录与管理」及其他 Tab，确认首张内容卡片顶部对齐，并检查窄窗口 / 高 DPI。

自动化只使用隔离临时数据库、目录和合成文件。Windows EXE 由 Draft PR 的 Actions 构建；自动化通过不代替真实游戏启动和界面验收。
