# butter-manager Roadmap

更新：2026-10-08。当前运行版 **0.3.0**，功能与恢复行为以 [v0.3 实施说明](v0.3-implementation.md) 为准，旧计划不作为待执行清单。

## v0.3 · 本地更新与存档保护

- [x] 批量导入、目录范围识别和隐藏/系统目录过滤；按名称、目录、别名匹配，弱关联显示理由并由用户决定。
- [x] 更新选择“保留旧存档”或“使用新包存档”，生成计划后执行前一次总确认；同版本来源副本可单独回收。
- [x] 同盘移动、跨盘单次复制；核对清单与大小，不做普通游戏资源内容指纹或逐个占用预检。进程、目录身份、路径、空间与恢复保护保留。
- [x] 内部旧存档覆盖到新版相同位置，外部存档不操作；存档复制保留必要校验。
- [x] 原 UUID、名称、别名、游玩状态、入库时间、存档配置和运行历史保留；schema 9 保存版本更新历史。
- [x] 中断继续/撤回、提交前恢复旧路径、成功项保留；成功后旧版进入回收站并清理暂存与存档临时副本。
- [x] 回退只从回收站恢复原旧版，按最近更新开始；当前内部存档带回旧版，换出版本进入回收站。清空回收站后无法回退。
- [x] 统一导入/更新进度；扫描与检查横幅先渐隐再收起位置，不挤压主列表。
- [x] 导入记录按游戏和日期展示，跨批次搜索；路径、存档与回退放入详情，回退及确认使用危险操作样式。
- [ ] 真实游戏更新和回退后的读档验收，至少 RPG Maker 与 Ren’Py 各一例。
- [ ] 若对外分发，补充干净 Windows 环境首次启动验收和发布说明。

自动化及构建已有通过记录；游戏自身的存档兼容性仍需验收。开发不备份正式数据库，不为更新永久保留旧游戏或在存档中放管理器文件。

## v0.3.1 · 稳定与界面打磨（规划）

- 收敛全局样式，明确详情字段、胶囊、行高亮的样式边界，改善窄窗口、长名称和长路径表现。
- 统一失败原因、阶段与继续/撤回提示，减少重复文案和无必要确认。
- 按实际大目录耗时定位剩余瓶颈，改善响应与性能诊断，不虚构进度。

## v0.4 · 随包 MTool 整理（规划）

- 保守识别完整重复工具，预览可释放空间、启动配置与公共 MTool 依赖。
- 验证配置切换后，由用户明确确认清理；回收站和恢复方案在实现前明确。
- 保留游戏资源、插件和未知内容，不执行随包 BAT。

## v0.5 · 识别与扫描效率（规划）

- 依据真实样本完善引擎、名称/别名和存档规则，记住人工匹配选择。
- 跨重启扫描缓存及明确的失效策略，避免目录变化后使用旧结果。
- 量化线程数、磁盘响应和最慢目录，以实测收益决定配置扩展。
