# 长列表滚动规范

2026-10-08。适用于当前 v0.3 界面；统一滚动保护也用于导入记录长列表，不修改数据库或启动逻辑。

- 所有页面使用同一套原生滚动条样式。WebView2 的轨道宽度为 12px，滑块可见部分为 6px；悬停和拖动时加深颜色。保留页面各自的滚动容器与圆角边界。
- 游戏库列表不在外壳底部预留白色横条，滚动视口直接延伸至圆角边缘；右侧轨道背景连续，边缘由外壳统一裁剪，避免底部留白挡住部分可见行。
- 游戏库列表行固定 88px，卡片固定 288px。标题最多两行，全文保留在按钮名称、悬停提示和游戏详情中。虚拟列表用确定高度计算总长度，移除滚动期间的逐行高度测量和重复清空尺寸缓存。
- 扫描与导入继续使用可变高度。共享 `useStableVirtualizer` 在滚动期间使用尺寸缓存或估算尺寸，同时临时固定可见项外框，避免动态内容改变滚动条比例。静止后外框恢复自然高度，ResizeObserver 更新尺寸；仅对完全位于视口上方的项补偿滚动位置。
- 若 WebView2 转发滚动条区域的 pointerdown，拖动保护持续至 pointerup、pointercancel 或窗口失焦；未转发时由虚拟列表的滚动状态保护。滚动结束后约 150ms 恢复自然高度测量。
- 虚拟列表关闭浏览器滚动锚定，避免浏览器与组件同时修正位置。普通详情、设置、许可文本和表单保持自然高度。
- 导入按分类与计划保存滚动位置；设置、MTool 各自保存位置，并在侧边栏往返后恢复。关于信息位于设置页底部，共用设置滚动区；没有独立 About 页面或滚动位置。搜索、排序变化仍回到顶部。
- 导入关联选择列表保持现有最多 50 项的限制，统一选项高度与长名称截断；系统原生文件选择器和 select 弹出菜单不替换。

接入时的历史验证：71 项前端自动化测试通过，包含 570 项游戏库的连续滚动与窗口变化、动态尺寸冻结与释放、暂停拖动、窗口失焦，以及导入和设置滚动位置恢复。类型检查通过。最新结果见 [验证记录](validation.md)。自动化夹具不代表已经验证 Windows 原生拖动手感，未使用 GUI 自动化。
