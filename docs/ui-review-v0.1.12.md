# v0.1.12 UI 与记录维护复查（2026-10-06）

依据：用户截图、组件 / 状态 / Rust 数据操作和自动化交互测试。未使用 GUI 自动化；DOM 测试不等同于实际 WebView 的视觉验收。

| 问题 | 处理 |
| --- | --- |
| 扫描页放大镜出现在侧栏设置附近 | 搜索容器设置定位基准，图标定位在自身框内。 |
| 搜索与排序错位、标签竖排 | 搜索框移除通用底边距；排序组不缩小、文字不换行，输入与选择器统一高度，空间不足时整组换行。 |
| 外部删除目录后旧记录无状态 | 启动 / 扫描结束自动后台检查，库提供主动检查；两线程，仅检查目录和有效启动路径。MTool 检查 target EXE。取消保留部分结果，状态会话内保存，缺失不自动删除。 |
| 用户难以集中处理失效记录 | 库显示缺失标签及需处理筛选，详情显示原因；已知目录 / 启动文件缺失时禁用启动，修正启动文件后重新检查。 |
| 移除游戏可能被误认为删除文件 | 详情单独确认仅删除该条库记录及关联记录；不提供磁盘删除动作。 |
| 改名 / 移动目录留下旧记录或重复登记 | 详情浏览新目录，或扫描候选显式选择旧记录；预览后确认。拒绝与其他 UUID 重复的安装目录，保留资料与历史。关联后刷新库和扫描已入库状态、清除相应勾选 / 过时分析。 |
| 操作晚到的列表读取可能复活旧记录 | 维护操作推进列表读取代次并重新取得权威库快照，旧登记查询不能覆盖新结果。 |
| MTool 页面只能配置，没有独立启动 / 检查 | 直接打开已保存共享根目录 MTool.exe，不带游戏参数；检查主程序和配置的 injector / runtime 是否可访问，报告逐文件结果。 |
| 未保存配置与当前操作不一致 | MTool 按钮在草稿修改时禁用；资料未保存、后台任务或维护请求进行中不能提交目录关联 / 删除记录。 |

目录关联只更新数据库路径，不搬动游戏文件、复制存档或推断新版本。旧根目录内的绝对存档路径按路径组件迁移到新根目录；外部路径、占位路径和带父级跳转的路径保持原值。单条移除会删除该条历史，不影响其他游戏和全局设置。

仍需后续验证：真实 MTool / 游戏兼容、原生文件选择器与 WebView 视觉、手动导入的版本匹配与保留存档文件更新 / 失败恢复。文件“可访问”只表示路径验证通过，不代表运行成功。目录状态不实时监听磁盘，变更后可主动检查。
