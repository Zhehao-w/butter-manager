# v0.1.15 全部滚动区域复查

检查依据：用户截图、所有当前使用的 overflow / scrollbar CSS 与组件结构，没有 GUI 自动化。以下是代码层面的修复 / 核对，不声称实际 WebView 视觉已实测。

| 滚动区域 | 检查结果与处理 |
| --- | --- |
| 游戏库卡片 | 整片网格不应承担圆角，取消 library-content / library-scroll 的圆角裁切，保留单张卡片圆角。右侧留 8px 内容间距，底部留 12px。 |
| 游戏库表格，含横向滚动 | 表格保留圆角外壳，tbody 为矩形，表头在滚动区外；底部预留 18px 避开外壳圆角，原有横向表头同步和虚拟行测量保持。 |
| 扫描结果 | 透明页面和滚动区均不裁切圆角；每张候选卡独立圆角。去掉左缩进，搜索后间距与库一致，非虚拟首卡额外 margin 清零。 |
| 导入流程 | 固定共用标题，卡片在独立矩形 import-scroll 内，内容起点与设置一致，保留原生滚动和右 / 底安全间距。 |
| MTool / 设置 / 关于 | 设置滚动区取消圆角，首卡片左 / 顶额外内外距移除，卡片从导入页相同内容起点开始。长说明仍换行、有足够行高。 |
| 游戏详情与确认 / 关联 popup | modal-scroll-shell 已将内容滚动区与外壳右侧 / 底部隔开，顶部在固定标题下方，不位于顶部圆角。沿用现有保护。 |
| 别名 / 存档路径多行输入 | 新增 text-scroll-shell，圆角边框与焦点提示在外层；内层 textarea 为矩形，滚动条和缩放角均离外边框至少 8px，键盘输入与标签不变。 |
| 开源许可 / 调试 BAT 长文本 | 共用 CodeBlock：外层背景圆角，内层 pre 无圆角且留 8px 边距。许可仍限制 220px 高度，长文本可换行，继续原生滚动。 |
| 侧边栏 | 自身与 app-shell 均无圆角，无相同裁切冲突，保留 overflow-y:auto 与现有底部内距。 |
| 诊断 / 运行历史 | 诊断在已保护的扫描列表 / 详情内容内，运行历史没有独立圆角滚动容器，不新增嵌套滚动。 |

全局原生滚动条继续保持蓝灰配色，不通过隐藏滚动条、覆盖自绘轨道或增加翻页规避问题。所有页面左内容起点一致；库 / 扫描的搜索栏从标题后的共用起点开始，卡片在搜索后相同间距处开始，保留这些页面必需的搜索控件。
