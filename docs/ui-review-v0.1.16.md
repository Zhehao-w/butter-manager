# v0.1.16 跨模块相同功能 UI 检查

本次依据布局代码与现有交互测试检查；未使用 GUI 自动化。实际 WebView 视觉仍需使用确认。

| 相同功能 | 原差异 / 处理 |
| --- | --- |
| 游戏库 / 扫描搜索 | 过去由 padding 和继承行高决定高度；改为共用 SearchField，44px 高、20px 行高、11px 上下内距、相同 20px 放大镜和定位、230px 最小宽度。删除模块重复规则。 |
| 游戏库 / 扫描排序 | 库有独立 padding / 最大宽度，扫描单独固定 44px；现在共用 SortField，44px 高、190px 宽、8px 标签间距、12px 文字且不换行。选项和排序行为保持。 |
| 搜索工具栏 | 两页统一 12px 控件间距、18px 下方内容间距；库内视图切换和需处理筛选外框统一 44px。窄窗口可换行，排序文字不竖排。 |
| 浏览目录 / 启动文件 / 存档 / 关联目录 | 共用 BrowseButton，16px 官方 folder 图标、普通 40px 高按钮，type=button；保留原回调、选择器边界、取消 / 错误 / 未保存行为。 |
| 普通路径输入 / 版本输入 / 配置下拉 | 共用 40px 高、20px 行高、11px 圆角和 focus 样式，路径输入与浏览按钮高度一致。多行输入沿用受保护的滚动外壳。 |
| 操作按钮 | 普通按钮最低 40px、同一字号；移除详情普通按钮的独立 12px 字号。标题文字按钮 / 通知关闭 / 视图切换内部按钮有明确紧凑例外；主启动强调按钮为 44px。 |
| 选中状态 | 需处理筛选和列表 / 卡片切换共用蓝色背景 / 边框 / 悬停配色，aria-pressed 保持；侧栏是导航，仍沿用导航选中样式。 |
| 标签与错误 | 表单 / 目录关联 / 候选版本标签共享颜色；设置错误改用 error 样式及 alert，任务锁定说明使用 notice / status，避免错误以普通灰字展示。详情稳定状态区域保持，避免启动反馈导致跳动。 |
| 页面标题 / 卡片 / 弹窗 / 滚动 | 沿用 PageHeader、CardTitle、Modal、滚动内缩和全局通知；没有发现需要新建另一套同功能样式的地方。游戏版本和时间继续复用 displayVersion / formatTime；保留文本含义与数据显示密度差异。 |

共用尺寸变量位于 :root，组件位于 ui.tsx。新增页面应复用这些组件，不再独立覆盖搜索 / 排序尺寸。本轮只改布局与展示，未更改扫描、保存、确认、启动、取消或资料处理流程。
