- 调整前的本轮实现仍在全库扫描中读取 PE / BAT：2 worker，60 秒请求取消，61,278 ms 结束，处理 464 / 571 个目录，首个完整结果约 42 ms。
- 去掉普通资源文件 metadata 查询、但仍读取 PE / BAT：同样在 60 秒请求取消，65,315 ms 结束，处理 526 / 571，首个完整结果约 39 ms。
- **最终默认快速扫描**将 PE 架构 / BAT 内容推迟到主动分析：2 worker，194 ms 处理完 571 / 571 个目录，首个完整结果约 11 ms，累计枚举 43,096 个目录项；558 个候选含 EXE，1 个目录分析未完整。

最后一次文件系统缓存已热，且工作范围有意减少，因此这些不是等工作量的冷缓存速度对比；不能宣称每次扫描只需 0.2 秒或固定加速倍数。首次 EXE 建议无需打开 PE / BAT，架构在主动分析前显示 Unknown；引擎只用文件名和少量固定标记推断。UI 约每 400 ms 取进度，后台首结果时间不等同于屏幕首帧时间。

取消测量验证了 worker 会结束、已完成结果保留；请求取消后一次分别还等待约 1.3 秒和 5.3 秒。正在进行的同步系统 I/O 不能承诺硬中断，界面先显示“正在取消，等待磁盘操作返回”。按需 EXE / BAT 分析也接入同一任务槽、进度和取消机制。
