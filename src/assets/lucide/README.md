# Lucide icons

Unmodified SVG files downloaded from [lucide-icons/lucide 0.468.0](https://github.com/lucide-icons/lucide/tree/0.468.0/icons) on 2026-10-06 and 2026-10-07. No icons in this directory were generated or drawn for butter-manager. The app packages the assets locally and does not fetch icons at runtime. Filter cards use semantic Lucide icons, not engine brand logos.

`sources.json` records the original URLs and SHA-256 hashes. `LICENSE` is the upstream ISC license. `FEATHER-LICENSE` is the MIT license for inherited Feather icons, downloaded from [Feather v4.29.2](https://github.com/feathericons/feather/blob/v4.29.2/LICENSE). See [Lucide licensing](https://lucide.dev/license).
